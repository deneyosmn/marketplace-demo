# İş Var - Hizmet Pazaryeri Demo Sitesi

Armut.com benzeri tam kurulmuş hizmet pazaryeri demo sitesi.

## Özellikler

- ✅ Responsive Tasarım
- ✅ Kategorili Hizmet Listeleme
- ✅ Hizmet Sağlayıcı Profilleri
- ✅ Yıldız Puanlama Sistemi
- ✅ Arama Fonksiyonu
- ✅ Admin Paneli
- ✅ Gerçek Görseller (Unsplash CDN)

## Kategoriler

1. **Temizlik** - Ev, ofis, cephe temizliği
2. **Tadilat** - Boya, fayans, kapı-pencere
3. **Nakliyat** - Evden eve, ofis, depolama
4. **Tamir** - Kombi, klima, beyaz eşya, elektrik
5. **Özel Ders** - Matematik, İngilizce, yazılım
6. **Organizasyon** - Düğün, parti, etkinlik

## Teknoloji Stack

- HTML5
- Tailwind CSS
- Vanilla JavaScript
- Font Awesome Icons
- Unsplash Image API

## Demo Verileri

24 farklı hizmet sağlayıcı örneği ile önceden yüklü.
